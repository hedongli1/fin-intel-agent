「金融/股票企业情报定时监控 Agent」已完成交付并通过我本人独立复核的冒烟测试。

## 结果概述

在项目目录下交付了 `fin-intel-agent/` 纯后端 Python 项目，实现你要的全部能力：

- **五维采集**：行情/股价、基本面/财务、新闻/公告/舆情、研报/机构评级、行业/板块 —— 全部由 `akshare` 一库覆盖（其新闻/快讯接口本身就是聚合自财联社·东方财富·新浪等公开源的联网聚合），无需申请任何搜索 API key。
- **定时调度**：APScheduler 支持盘前 09:30 / 盘后 15:30 两档（配置化可改），并内置交易日判断（非交易日自动跳过）。
- **飞书推送**：群机器人 webhook 推送，超长报告自动按行分片（规避飞书 20KB 上限），webhook 留空时自动降级为 stdout 打印（dry-run）。
- **可维护性**：分层结构（collectors/aggregator/notifier/scheduler），pydantic 强校验配置，loguru 日志，每个采集器异常隔离（单维度失败不影响整体）。
- **验证结论**：我亲自跑 `python3 -m src.fin_intel --once --dry-run`，EXIT=0、零未捕获异常，三只标杆股（贵州茅台/宁德时代/中国平安）五维均回流真实数据。

## 使用方式

```bash
cd fin-intel-agent
python3 -m venv .venv && source .venv/bin/activate      # 建议用 venv（本沙箱是 --break-system-packages 装的）
pip install -r requirements.txt                          # 网络慢可加 -i https://pypi.tuna.tsinghua.edu.cn/simple

python3 -m src.fin_intel --once --dry-run   # 一次性采集+打印，不推送（先这样验证）
python3 -m src.fin_intel --once             # 一次性采集并按配置推送到飞书
python3 -m src.fin_intel                    # 常驻：按盘前/盘后定时自动推送
```

部署可选 Docker（已给 Dockerfile）或 systemd（`deploy/fin-intel-agent.service`）。

## 注意事项（需要你动手的仅这几处）

1. **填飞书 webhook**：打开 `config/config.yaml`，把 `feishu.webhook_url` 填上（建群 → 群设置 → 群机器人 → 自定义机器人 → 复制 webhook）；留空则永远只打印不推送。
2. **改企业清单**：同文件 `watchlist` 下按「6 位代码 + 名称」增删，示例是贵州茅台/宁德时代/中国平安。
3. **正式推送前**：把 `app.dry_run` 改成 `false`；确认 `schedule.skip_non_trading_days: true` 符合预期（周日/节假日不推）。
4. **首版只做 A 股**：港股/美股接口稳定性弱，后续需要再扩展。
5. 报告中已内置免责声明（仅供研究参考、不构成投资建议）；数据有延迟，以官方披露为准。
